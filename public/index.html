ORBIT: AI Social Robot with Acoustic Trilateration

2025 – Present
Golden Codex (WRO Senior Open) • Lead Embedded Engineer

An autonomous social robotics platform engineered for public cultural and museum spaces. Integrates a custom acoustic trilateration localization algorithm running on 3 directional microphones positioned at 120-degree offsets. The system processes time-difference-of-arrival (TDoA) audio phase signals in C++ to physically locate, track, and orient toward human speakers in real-world ambient noise.

Coordinator Raspberry Pi 5 (8GB) running high-level conversational AI
Localization 3-Directional microphone array with TDoA acoustic trilateration

Automated Maritime Tide Monitoring System

2023
Tomorrow’s Innovators (WRO Team) • Firmware & Prototyping

Autonomous coastal safety alert station mitigating ship grounding hazards and protecting fragile coral reef formations during sudden tidal drops. Submerged multi-depth conductivity probes are monitored by an Arduino UNO running C++ signal debounce and analog hysteresis filters to filter natural wave action from true tide shift, triggering real-time optical navigation warnings.

Embedded Core Arduino UNO microcontroller with C++ analog threshold processing
Submersible Hardware Waterproof terminal array with conductivity sensor integration
Validation Apparatus Closed-loop water-pump fluid simulation rig for dynamic spike testing
World Standing Ranked #19 Worldwide & #4 in the Americas (WRO Panama 2023)

Autonomous Microgreen Agricultural System

2024
Tomorrow’s Innovators • Systems Architecture

Closed-loop agricultural robot delivering an autonomous 8-day seed-to-harvest microgreen growth cycle. Aligned with UN SDG-12 (Responsible Consumption and Production).
